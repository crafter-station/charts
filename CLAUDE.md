# @crafter/charts

Recharts for your terminal: 15 chart types (braille line, bar, scatter, candlestick, sparklines, heatmap, histogram, gauge) as a zero-dependency TypeScript library. See [AGENTS.md](./AGENTS.md) for the full API, usage patterns, and pitfalls.

Repo development uses Bun: `bun install`, `bun test`, `bun run build`.
